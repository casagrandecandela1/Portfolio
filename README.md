**💣 Juego "Desactivar bomba" – Trabajo práctico final - Materia Laboratorio de computación I.**

Proyecto realizado en equipo para la materia Laboratorio de Computación 1 de la carrera de Programación Informática.

El objetivo fue desarrollar un juego interactivo estilo “desactivar la bomba” utilizando Arduino y componentes electrónicos básicos, integrando conceptos de programación en C, lógica y hardware.

El juego simula una bomba con cuenta regresiva donde el jugador debe adivinar un código de 4 dígitos antes de que el tiempo llegue a cero. Si el jugador se equivoca, pierde 10 segundos para seguir intentando acertar y suena una bocina indicando el error. El sistema indica si la bomba fue desactivada correctamente o si “explota”.

**Tecnologías y componentes utilizados:**
- Arduino
- Lenguaje C para Arduino
- Protoboard
- LEDs
- Buzzer
- Display LCD 
- Resistencias y cables
- Botonera
  
**Funcionalidades:**
Cuenta regresiva automática
Interacción mediante botones
Señales visuales y sonoras
Condiciones de victoria y derrota
Simulación de bomba estilo arcade

**Conceptos aplicados:**
Entradas y salidas digitales
Manejo de tiempo con millis() / delay()
Control de componentes electrónicos
Estructuras condicionales
Integración hardware + software

**Objetivo del proyecto**
Además de cumplir con los requisitos de la materia, este proyecto me permitió practicar:
Lógica de programación, resolución de problemas, conexión de circuitos electrónicos,y desarrollo de proyectos interactivos con microcontroladores.
